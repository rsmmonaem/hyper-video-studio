# Thumbnail Studio Skill

Generates click-worthy, YouTube and Reels standard visual covers.

## Design Rules
1. **Flawless Bengali Typography**: Loads Google Fonts Hind Siliguri ensuring zero broken ligatures.
2. **Dual Aspect Formats**:
   - `16:9` (1920x1080) for standard YouTube video thumbnails.
   - `9:16` (1080x1920) for Instagram Reels and YouTube Shorts covers.
3. **High-Contrast Layering**:
   - Kicker Pill (e.g. `🔥 10X PRODUCTION SCALE`)
   - Main headline with dual-tone gradient fill and drop-shadow
   - Tech stack tags (`#Nginx`, `#LoadBalancer`, `#DevOps`)
   - Action CTA (`WATCH NOW ⚡`)
