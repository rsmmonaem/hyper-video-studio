# Content Planner Skill

Autonomous director that formulates high-retention engineering narratives optimized for YouTube Shorts, Reels, and developer communities.

## Structural Pacing Formula (30–35s Standard)
- **Scene 1: High-Stakes Dilemma (00:00 — 00:07)**:
  Direct question hook challenging standard assumptions (e.g., "10x traffic spike without crashing").
- **Scene 2: Architectural Breakdown / Bottleneck (00:07 — 00:15)**:
  Exposes the point of failure (CPU 100%, database connection pool exhaustion, full table scans).
- **Scene 3: Scalable Solution Architecture (00:15 — 00:27)**:
  Visual solution with reverse proxy, load balancer, distributed caching, or indexing.
- **Scene 4: Production Rules & Creator Branding (00:27 — 00:35)**:
  Actionable takeaways + FTLTD brand signature + Subscribe CTA.
